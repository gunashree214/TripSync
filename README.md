# TripSync

TripSync is a simple travel planning website that helps users organize and manage their trips in one place.

## Features

- Create and plan trips
- Explore destinations
- Create itineraries
- Save trips
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Git & GitHub
